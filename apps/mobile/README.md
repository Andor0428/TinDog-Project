# BarkSpark Mobile (iOS + Android)

Cross-platform app scaffold using Expo + React Native + TypeScript.

## See the app locally
From `apps/mobile`:

1. Install dependencies
   ```bash
   npm install
   ```
2. Start Expo
   ```bash
   npm run start
   ```
3. Install on your phone with QR code
   - Install **Expo Go** from App Store / Google Play.
   - In the Expo terminal, scan the QR code with:
     - iOS Camera app, or
     - Expo Go QR scanner on Android.
4. Open emulator/simulator (optional)
   - Press `i` for iOS Simulator
   - Press `a` for Android Emulator
5. Optional web preview
   ```bash
   npm run web
   ```

## Current implemented flows
- Seeded onboarding flow (first launch only)
- Discover with swipe gestures (left pass / right like)
- Free tier like-limit and upgrade CTA
- Matches, Events, Profile placeholders
